# Paper draft

`agent-warden.tex` is a ~5-page workshop paper draft (pdfLaTeX, no external .bib file).
Compile it on Overleaf, or locally with `latexmk -pdf agent-warden.tex`.

All numbers are filled from the committed results (`results/REPORT.md`, `results/GATEWAY_*.md`, `results/DETECTOR.md`).

Venue candidates are AI-security workshops co-located with ML or security conferences. Check each call for page limits and anonymity rules before submitting (anonymous submissions need the author name and GitHub link removed).
